# Templates

Starting shapes for documents you write often. The AI reaches for one instead of inventing a structure every time.

## How the AI uses these

- Before writing a PRD, a decision record or anything else with a template here, **read the template and use it**. Do not invent a different structure and do not silently improve on it.
- If the human's situation does not fit the template, say which sections you are dropping and why. Adapting is fine, quiet drift is not.
- If there is no template for what they need, write the document and then **offer** to save its shape as a new template.
- Templates are shapes, not forms. A section with nothing real in it gets deleted, not filled with filler.

## What is here

| Template | Use it for |
|---|---|
| `one-page-prd.md` | Defining what to build before building it. Fits on one page on purpose. |
| `decision-record.md` | Any call worth being able to explain in three months. Lands in a project's `decisions/`. |

## Adding a template

One file per template, readable name, and a one-line entry in the table above. Keep them short - a template long enough to feel thorough is long enough to get skipped.
