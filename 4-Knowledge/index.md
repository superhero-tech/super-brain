# Knowledge Index

A categorised list of every wiki page in this folder. The AI updates this file after every Ingest.

It starts empty. It fills up after your first ingests.

## Format

Concept pages, grouped by domain:

```
### [Subfolder / Category]
- [[Page Name]] - one-sentence description
```

Entity pages, listed separately - they are hubs, and keeping them apart makes it obvious when one is missing:

```
### People
- [[Name]] - who they are, in five words

### Companies & Tools
- [[Name]] - what it is, in five words
```
