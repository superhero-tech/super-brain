# Knowledge Log

Chronological history of everything done to the wiki. Append-only - never edit an old entry.

Four actions: `ingest`, `query`, `lint`, `update`.

## Formats

```
## [YYYY-MM-DD] ingest | short description
Source: file-name.md
Pages: Page A (created), Page B (updated), Page C (updated)
```

```
## [YYYY-MM-DD] query | short description
Question: [as asked]
Pages read: Page A, Page B
Output: 9-Outputs/YYYY-MM-DD-slug.md
Filed back: [page name, or: no]
```

```
## [YYYY-MM-DD] lint | short description
Report: 4-Knowledge/lint-YYYY-MM-DD.md
Found: x errors, y warnings, z notes
```

```
## [YYYY-MM-DD] update | short description
Pages: Page A (updated), Page B (created)
Why: [output filed back / lint fix / correction]
```
