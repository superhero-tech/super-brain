# Credits

Super Brain was built by **Wojtek Strzalkowski** and **Piotr Kacala** at [superhero.tech](https://superhero.tech), for **AI Product Heroes**.

The knowledge loop is an adaptation of Andrej Karpathy's LLM knowledge base method: dump raw sources into a folder, have an LLM compile them into a linked markdown wiki, then query the wiki instead of the sources.

- Original post: https://x.com/karpathy/status/2039805659525644595

Use it, fork it, take it to your next job.
